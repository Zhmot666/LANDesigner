## Форматы данных

| Формат | Назначение |
|--------|------------|
| `.lanproj` | Основной файл проекта (SQLite + assets) |
| `.lanproj.assets/` | Подложки планов этажей (рядом с проектом) |
| `.ldtypes` | Пресет типов устройств (экспорт/импорт каталога) |
| CSV `#LANDESIGNER_CSV` | Полный обмен данными проекта (Файл → Экспорт/Импорт CSV) |
| `.lanproj.sync.json` | Привязка локального файла к remote id (рядом с `.lanproj`) |
