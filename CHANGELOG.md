## [0.1.0] — 2026-08-25

Срез текущего продукта: LAN CAD + CMDB lite, sync, отчёты.

### Added

#### Кабели и документация соединений

- Смешанная **автогенерация меток** кабелей: `CAB-NNNN · назначение: host/port ↔ host/port`.
- Эвристика **назначения** по ролям устройств (WAN, uplink, рабочее место и др.).
- Кнопка «Сгенерировать…» в диалоге кабеля; автоподстановка при выборе портов.
- Массовое заполнение пустых меток: **Отчёты → Заполнить метки кабелей**.
- Поля кабеля: цвет, назначение; путь через патч-панель в отчётах и tooltip.

#### Файлы и старт

- Меню **Файл → Последние** (до 12 проектов), очистка списка, старт диалога «Открыть» в папке последнего проекта.
- Иконка приложения, старт в развёрнутом окне.
- Локальные **снимки** проекта (создать / восстановить).

#### Инвентарь и роли

- Расширенные роли устройств (FIREWALL, LOAD_BALANCER, STORAGE, PDU, UPS, KVM, NVR, IP_PHONE, PRINTER, MODEM, CONTROLLER, ODF и др.).
- **LAG/bond** (Active-Backup / LACP / Static), IP на LAG.
- **VRF**: справочник, привязка IP, уникальность в пределах VRF; отчёт «VRF / IP scope».
- ВМ / гипервизор: `host_device_id`, vNIC→NIC, vSwitch / Port Group.
- Шкафы, юниты, **двусторонний монтаж** (Front / Rear / Full).
- Патч-панели: Front/Rear, матрица пар, быстрый кабель с порта.
- Типы устройств **без портов** (ИБП/PDU и т.п.).
- Вкладка **Каталог**, пресеты `.ldtypes`.

#### CAD

- Схема топологии: snap, автораскладка, VLAN/скорость на линках, групповое перемещение (Undo).
- План этажа: маркеры, трассы (`FloorPlanRoute`) с длиной, легенда ролей, групповой drag.
- Чертёж стойки 2.0: Front/Rear, DnD по U, свободные U, отчёт «Шкафы / юниты».

#### Отчёты и проверки

- Табличные отчёты: оборудование, порты, кабели, VLAN, VRF, шкафы.
- Экспорт отчёта в **CSV** и **PDF**, печать.
- Валидация проекта (дубли IP, порты/кабели, метки, ВМ, PP, схема/план и др.).

#### Синхронизация

- Меню «Синхронизация», `.lanproj.sync.json`, push/pull, конфликты.
- Diff локального/серверного при конфликте Push; проверка соединения; ошибки 401.
- Team sync locks, бэкапы при pull.
- Сервер: FastAPI + SQLite или **PostgreSQL**; Docker Compose.

#### Документация

- Руководство пользователя, документация sync-сервера, демо-проект `examples/demo-office.lanproj`.

### Changed

- Улучшения UX: сайдбар «Площадка», форма каталога, 1U в стойке, валидация диалогов устройства/типа до закрытия.
- Порядок вкладок: Каталог — последняя; по умолчанию открывается Инвентарь.

### Fixed

- Разные точечные исправления UI/валидации в ходе итераций (см. историю git).

## Как вести дальше

1. Новые изменения — в секцию **[Unreleased]** (Added / Changed / Fixed / Docs).
2. При релизе: переименовать Unreleased → `[x.y.z] — YYYY-MM-DD`, обновить `version` в `pyproject.toml`, при необходимости git-tag.
3. Не писать сюда внутренние WIP-заметки агента — для этого `.cursor/rules/landesigner-status.mdc`.

Ссылки на коммиты: `git log --oneline`.
